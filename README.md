# 樱花动漫

> 樱花动漫 (Yhdm)，一款看动漫的软件。

## 功能

- **追番**：从 Bangumi 拉取番剧信息，浏览热门榜、日放、季度新番
- **观看**：多规则源聚合播放，支持选集、倍速、画中画、播放记录与续播
- **弹幕**：自建弹幕接口，支持手动检索、弹幕发送、透明度、倍速下生效
- **规则插件**：内置/自定义规则市场，支持批量导入
- **评论**：番剧吐槽/评论，支持 BBCode 格式、BGM 表情回应、举报
- **关联作品**：点击详情页「相关」，看到续集/前传/衍生等官方关联条目
- **收藏**：追/看/吃/扔/搁 五档收藏，个人收藏夹与历史记录
- **下载**：离线缓存下载，下载选集自动定位到当前播放集
- **搜索**：番剧关键词搜索、以图搜番
- **社交**：好友系统
- **设置**：镜像/代理、界面、播放、弹幕、通知等

## 体验

- Android：已支持
- iOS：后续会添加

- 支持深色、跟随系统
- 桌面端键盘快捷键、鼠标悬停手势

## 数据

- 番剧、评分、评论、关联来自 Bangumi
